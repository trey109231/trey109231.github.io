USB HID protocol reverse engineering

Razer Mouse Control

Recovered mouse configuration protocols and built standalone Python control utilities for the DeathAdder 2013 and Viper Mini.

View on GitHub

Motivation

Built a lightweight alternative to vendor software for configuring supported mice, using direct USB HID communication.

Protocol recovery

Investigated installer resources, native x86 libraries, managed .NET components, and extracted firmware. Used Ghidra analysis and USBPcap/Wireshark captures to recover report framing, checksums, command encodings, and device-specific configuration fields.

Implementation and verification

Implemented DPI, polling, and device-specific lighting controls in Python utilities. Protocol handling validates transaction IDs, command echoes, checksums, and device status. Hardware tests compare configuration readback after writes and restore baseline settings.

Scope

Device capabilities differ between the DeathAdder 2013 and Viper Mini. The utilities target their supported configuration features rather than reproducing the entire Synapse suite.
