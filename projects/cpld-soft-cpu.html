4-bit Soft CPU on a MAX II CPLD

A custom accumulator CPU on an EPM240 CPLD, executing an instruction-timed software UART routine.

Processor architecture

Implemented a four-bit datapath with a 12-instruction set, ROM program, conditional branches, and single-level CALL/RET support.

UART in software

The ROM program changes an output through timed instructions to generate UART transmission. This exercises the processor instruction and control path rather than using a dedicated RTL UART transmitter.

Hardware validation

Programmed the MAX II EPM240 and verified UART output on hardware. The project demonstrates instruction decoding, accumulator/control logic, and timing within a small CPLD. Resource-utilization figures are not claimed without a fitter report.
