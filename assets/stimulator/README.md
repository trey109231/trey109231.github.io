# Rev 1 stimulation instrument figures

The `rev1-*` figures are extracted from Trey Kirscht's *Design and Validation
of an Eight-Lane Routed Stimulation Instrument for 48-Electrode Intraspinal
Microstimulation*, WKEXP 905 technical report, Summer 2026.

`projects/stimulator-platform.html` uses the following annotated figures:

| File stem | Report figure | Content |
| --- | --- | --- |
| `rev1-system-architecture` | 1 | Control, acquisition and retained-evidence architecture |
| `rev1-lane-schematic` | 2 | Representative source/sink lane and measurement circuitry |
| `rev1-breadboard-annotated` | 3 | Early one-lane prototype |
| `rev1-pcb-layout` | 4 | Completed four-layer PCB layout |
| `rev1-assembled-bench` | 5 | Assembled PCB, enclosure and passive-load fixture |
| `rev1-desktop-operator` | 6 | StimWaveGen desktop timeline and operator interface |
| `rev1-web-operator` | 7 | Raspberry Pi web operator |

PNG files retain the extracted source resolution. WebP versions are used for
page display; each figure links to its full-resolution PNG. Figure labels and
annotations come from the report, rather than reconstructed graphics.

Only the relevant figures are published here. The complete report is not
included. Older `stimulator-*` images are retained as historical assets but are
no longer used on the updated Rev 1 page.
