RTOS / embedded systems internals

BadRTOS: Preemptive AVR RTOS

A small RTOS lineage that began with a PIC16F84A TinyRTOS-style assembly runtime using a Timer0 tick, cooperative task timing, heartbeat modes, debounced button input, software PWM, and bit-banged UART telemetry, then grew into a preemptive ATmega328P RTOS in C and AVR assembly with task stacks, semaphores, mutex priority inheritance, mailbox IPC, stack monitoring, UART diagnostics, and hardware validation.
